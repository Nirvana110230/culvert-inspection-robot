# 决策、失败尝试与实验讨论

| 工程问题 | 试验与判断 | 会话定位 |
| --- | --- | --- |
| 履带控制接口 | 现场照片中可见的线端、商家说法和模块手册之间仍有待核实的对应关系。先追 W003 的另一端，留下测量条件，确认接口前保留协议判断。 | [履带接线，助手 3.5](sessions/H029.md#m-3-5) |
| 相机几何与时间 | 内参以覆盖范围和留出误差复核。雷达与相机外参另有多场景验证，传感器曝光时刻的绝对对齐仍需相应观测。 | [内参采集与验收](sessions/H030.md)、[外参条件，助手 9.9](sessions/H031.md#m-9-9)、[跨设备时间](sessions/H033.md) |
| 长时间建图的内存增长 | 原定 30 分钟的实验在 370.444 秒触发资源保护。后续沿视觉点、特征与共享灰度图的引用关系回收，短测记录了 189 张历史图像释放最后引用。长时平台值仍需在相同配置下测量。 | [触发保护，助手 2.8](sessions/H043.md#m-2-8)、[图像回收，助手 1.20](sessions/H047.md#m-1-20) |
| 同一手持包多次回放产生分歧 | 初始化修复 B0 保留首帧雷达前有效 IMU。隔离实验中三次回放一致。尾段运动缺少独立真值，正式部署继续锁在 A。 | [回放比较，助手 3.7](sessions/H062.md#m-3-7) |
| 轮式固件烧录和停车验证 | 正式固件会话记载了 31,248 字节回读。引用该数值时需要区分历史回复、输入 BIN、独立回读副本与烧录日志。串口接收、状态反馈和整车机械停车还需要各自的证据。 | [回读陈述，助手 3.4](sessions/H064.md#m-3-4)、[接口与交接](sessions/H020.md)、[底盘恢复](sessions/H063.md) |
| 涵洞重复结构使低残差候选也可能错锁 | ICP 和 GICP 在同一留出集比较。53 个可定位正例中，两者分别正确放行 38 和 45 个，错误接受 12 和 2 个。相似地图挑战出现相隔 32 米的廊段也被接受，后续需多帧确认及独立复访。 | [定位比较与适用范围，助手 1.7](sessions/H068.md#m-1-7) |
| 板端连接与整仓恢复 | G2 对固件、配置、证据与本地恢复作了收尾记录。随后香橙派 USB SSH 会话记录了连接检查和结果。恢复工程文件、确认可访问目标和完成整车实验是三个需要分别记录的环节。 | [G2 结束答复](sessions/H071.md#m-1-10)、[USB SSH](sessions/H072.md) |

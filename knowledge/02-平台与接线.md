# 轮式研究平台与履带交付平台

轮式底盘承担 FAST-LIVO2 搭载测试，并供后续毕业设计接续。新版遥控固件恢复了用户现场确认的遥控运动。下一阶段的轮速反馈、载荷下制动距离及导航闭环需要独立记录。二代四驱设计使用前后桥驱动器，其接线图不构成二代实车完成证据。

履带底盘承担最终项目交付。P001–P011 共 11 张照片支持 21 条单端线记录，双端闭合 0 条、实际电测 0 项。数字模块 ZS-DIO-R-10A-8 的 RS485 标识、线套管 H/L、商家 CAN 口述存在 C13 冲突；模拟模块显示 0–5 V、双通道和 CAN 选项。项目接续从 W003 远端、控制器铭牌、急停及手动仲裁电路取证。原工作表与带证据编号的工作副本均在 vehicle-project.zip。

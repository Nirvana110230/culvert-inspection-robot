# 已采用的决定、依据和遗留问题

| 问题 | 已采取的处理与依据 | 接续时判断什么 |
|---|---|---|
| 轮式与履带硬件及用途不同 | 总仓按平台分别锁定组件；用户指定轮式测试与毕设、履带最终交付 | 履带控制链须单独验收 |
| 视觉点增长与历史图像占用 | 体素取键修正、按所有权做 LRU，实测历史图像释放 | 监控持续 RSS/PSS 与内存保护退出条件 |
| 同袋多次轨迹分歧 | B0 保留启动期有效 IMU，三次回放复现一致 | 对尾段退化补独立运动真值再决定是否升级 |
| 重复涵洞导致低残差错锁 | 离线保留 ICP 基准、近初值测试 GICP、比较多个候选及错图 | R3 的多帧确认、退化、失锁与恢复 |
| 接收器失联仍可能持续给出 PWM | 旧板测已登记行为，手动协议与物理停车分别取证 | 发射机关机行为与实车制动距离分别核对 |
| 履带数字模块标记冲突 | 保留照片、手册和商家原话，先追 W003 | 双端连接与电气实测补齐后确定总线 |
| 软件交接与数据权属 | 候选仅纳入审查过的输入，原始实验和会话在受限区索引 | 迁移前明确课题组授权、上游许可证、远端身份 |

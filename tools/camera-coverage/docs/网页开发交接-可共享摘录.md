## 2. 模型、坐标与原始默认参数

涵洞的基准截面是**净宽 2.00 m、总高 2.00 m、直墙高 1.00 m，上部为半径 1.00 m 的半圆**。不是总高 1.50 m。网页默认显示长 10.00 m 的一段，两端开口；10 m 是仿真长度，不代表实地涵洞全长。改变宽度、总高或直墙高后，上部可成为半椭圆。

底盘长 × 宽 × 高为 **0.80 × 0.61 × 0.67 m**。原始布局将车辆放在显示段中央，无横向偏移、无车体偏航，模拟车速为 **0.20 m/s**。相机坐标原点是**车体中心在地面的投影**：x 正向朝车头，y 正向朝车左，z 是光心离地高度。偏航 0° 朝车头，正值左转；俯仰正值上仰。下表的三台相机都启用，滚转均为 0°。

| 相机／颜色 | 用途 | x, y, z（m） | 偏航 / 俯仰 | 水平 / 垂直视场 |
| --- | --- | --- | --- | --- |
| 主云台／金色 | 左前上视，观察拱顶和上部侧壁 | +0.16, 0.00, 0.87 | +35.0° / +20.0° | 68.38° / 41.83° |
| 上后摄／青色 | 从车尾观察左侧壁下部 | −0.40, 0.00, 0.97 | +91.3° / −21.4° | 58.30° / 34.84° |
| 下后摄／珊瑚色 | 从车尾向左后下方观察墙根、近地带；实际巡检也关心部分水面 | −0.40, 0.00, 0.75 | +120.0° / −50.0° | 58.30° / 34.84° |

共同默认值：**3840 × 2160、25 fps、曝光 1/500 s、可视化量程 4.0 m、16:9 视角联动开启**。4 m 仅限制仿真射线长度。显示设置默认开启剖开洞壁、视场体、覆盖投影、车体遮挡和网格，洞壁不透明度为 0.11。表内角度取两位小数；复现计算应使用原始 JSON 的精度。已对照原文件、源码和离线 HTML：除原文件自带导出时间外，三者的布局参数一致。

**复现实机后摄的操作：** 先导出当前方案。在“场景”里把车速设为 0.80 m/s；分别选上、下后摄，**先关掉“按 16:9 联动水平 / 垂直视角”**，再填 79°、43.3°、3840 × 2160 和 20 fps。如果保留联动，输入 79° 会把垂直视角自动算成约 **49.75°**，与规格表不同。未获得新的安装测量前，可以沿用旧方案的光心和姿态来做镜头对照，并将结果另存为一个 JSON。建议将来把这组设置新增为“已购 4 mm 后摄”预设，保留“恢复默认”对应的原上传方案。

## 4. 已实现的交互与导出要求

| 用户要做的事 | 当前做法与需要保留的体验 |
| --- | --- |
| 看三台相机拍到哪里 | 主视图可旋转、平移、缩放，并切换三维透视、正视截面、俯视或侧视。矩形画幅用四棱锥表示；彩色投影显示落在墙、拱或地面的范围，可开关车体遮挡。主视图随面板大小改变，出图前按最终窗口比例检查构图。 |
| 调位置、转向、俯仰和镜头 | 三机独立启用，可调 x/y/z、偏航、俯仰、滚转、双向视角、量程，支持横竖装、数字输入、滑块和 ± 微调。默认慢 5 倍，可切标准或慢 20 倍；拖动时按 Shift 再减速。安装位置步进 0.01 m，姿态步进 0.1°，视场角步进 0.01°。 |
| 用键盘比较方案 | 非输入状态下按 1/2/3 切相机，方向键调所选相机的偏航或俯仰（1°，按 Shift 为 5°），R 归位观察视角。观察者视角与机器人相机朝向是两件事。 |
| 把主画面腾出来 | 顶部“相机预览”可隐藏或恢复当前相机的小窗，不关闭这台相机或其视场。桌面右侧分隔线调侧栏**宽度**，下方分隔线调底栏**高度**；可用键盘调整、双击恢复面板默认尺寸。显示偏好保存在本机。 |
| 导出报告用图 | 调好三维观察角度再点“导出高清图”。按当前朝向、平移、缩放和主视图宽高比重新渲染 PNG，长边可选 1920、**3840（默认）**、5760 px；背景可选深色、白色、透明。不是截整页。 |
| 区分图中标记与界面文字 | 页面标题、宣传句、涵洞尺寸串、尺寸标注、相机预览、侧栏和底栏不进入 PNG。“保留三台相机名称”默认开启，可取消。模型中的“车头”和墙面 L/R 参考标记属于场景对象；若下一步要求**任何文字都不能出现**，还需给这两类标记加导出开关。 |
| 保存与交流 | 参数在当前浏览器本机自动保存；不同电脑不会自动同步。参数 JSON 可导入/导出涵洞、车辆、显示开关及三机布局；不会保存观察者的旋转、平移、缩放。要交接某个精确构图，请同时留 PNG；如需可编辑地重现构图，需新增观察视角存取。 |

## 5. 怎样读覆盖率与清晰度

- **彩色壁面投影**回答“现在照到哪里”。射线沿针孔模型发出，在首个洞壁、拱面、地面或启用的车体遮挡处截止；透明剖开洞壁只是为了便于观察。相机小窗是几何预览，不是真机视频。
- **洞壁展开图**表示当前车辆位置和三机姿态的瞬时覆盖。**截面周界覆盖**则沿涵洞轴向检查：某一周界高度区间只要在某个纵向位置可见，就计为覆盖。统计包含两侧直墙和拱面、不含地面；它不是整段内壁的已拍面积百分比，也不是每个纵断面都达到该比例。
- **中心附近采样（px/mm）**取相机中心射线命中点，在该点的切平面估算最不利方向。下后摄在原始姿态下中心命中的是**地面**，它的中心读数不能当成墙根处的清晰度。“运动模糊”仅按匀速直线平移和曝光时间估算。网页未模拟水面反射、补光、镜头畸变、对焦、压缩、车身振动或滚动快门，不能据此承诺缺陷检出率。

**可重复的数值核对：** 恢复上传默认值、车辆居中且静止在该位置，保留默认模拟车速和遮挡设置。在交接版本按几何代码复算如下。它们用于发现坐标方向、相机顺序或单位改错，不是实测报告。

| 指标 | 主云台 | 上后摄 | 下后摄 |
| --- | ---: | ---: | ---: |
| 中心射线首次命中 | 拱面 | 左侧壁 | 地面 |
| 光心到命中点距离 | 1.67 m | 1.07 m | 0.98 m |
| 中心附近最保守采样 | 1.08 px/mm | 2.98 px/mm | 2.69 px/mm |

三机合计的截面周界覆盖界面显示 **53%**（当前默认离散网格值 53.125%）。调整量程、相机启用状态、车体位置或观察用仿真段长度都可能改变这个数；只旋转屏幕上的观察视角不应改变它。

## 6. 开发入口、运行与验收

本项目是静态 HTML / CSS / JavaScript，Three.js 0.170.0 和 OrbitControls 随包提供，无运行时外部 CDN。源码直接维护 `dist/` 中的模块；普通模块版应通过 HTTP 服务访问。可双击的是上文的**独立离线单文件**，不是源码目录里的 `dist/index.html`。

| 位置 | 何时看这里 |
| --- | --- |
| `dist/geometry.js` | 原始默认值、坐标变换、针孔投影、解析求交、车体遮挡、周界覆盖、采样与模糊、JSON 校验。 |
| `dist/scene.js`、`dist/software-renderer.js` | 三维场景、三机视场与落点、相机预览、保持构图的 PNG 导出；缺少 WebGL 时的 Canvas 2D 兼容绘制。 |
| `dist/app.js`、`dist/slider.js` | 参数、滑块、镜头预设、键盘、运行状态、行进、覆盖图，以及 JSON 导入导出。 |
| `dist/workspace.js`、`dist/index.html`、`dist/style.css` | 相机预览开关、分隔线、导出设置、页面控件与响应式布局。 |
| `dist/vendor/`、`tests/geometry.test.mjs`、`.openai/hosting.json` | 本地图形依赖与许可证、几何回归测试、原站点 ID 及静态入口。 |

从仓库根目录运行：

```sh
node --test tests/geometry.test.mjs
python3 -m http.server 8000 --directory dist
```

第二条用于本机预览，浏览器打开 `http://localhost:8000/`。版本沿革：V1.0 建立仿真；V1.1 增加精调；V1.2 接入上传布局、可隐藏预览、可调面板和高清导出。离线单文件是同版另外交付的文件；当前仓库内没有离线打包脚本，修改在线源码不会自动更新离线版。

**验证记录：** 本次重新运行 6 项几何测试，全部通过；同时核对了发布提交、原始 JSON 和离线默认值。仓库已有浏览器验收记录，涵盖精调、分隔线与设置记忆、预览隐藏、恢复默认及 PNG：例如深色 3840 × 2292、透明/白色 1920 × 1146。短边取决于当时构图。该记录主要验证 Canvas 兼容路径；本次未重新做浏览器全流程、真机 WebGL 或大陆网络实测。

**下一版至少复核四件事：**

1. **参数**：原始 JSON 往返后数值一致；若添加实机预设，79° 与 43.3° 能同时保留，并且只改所选后摄。
2. **交互**：能低速微调、直接输数、隐藏预览和拖动两个分隔线；只改主视图观察角度不会改三机朝向或覆盖率。
3. **导出**：先旋转、平移、缩放，再导出 PNG；核对构图、长边像素、透明背景、相机名称开关，以及用户明确排除的宣传语和尺寸文字。
4. **分发**：在线版检查匿名访问；离线版在禁网后重新打开，验证三维、调参、参数导入导出和 PNG。若要交付国内直达网址，必须另有可访问的静态托管或单位内网服务，并由目标网络实测。同事已拿到 HTML 可以断网使用，不代表目前的在线链接已完成国内部署。

# 涵洞巡检相机视场实验室

双击 [V1.3 离线网页](releases/v1.3/culvert-camera-lab-V1.3.0-offline.html) 可观察已购双后摄方案。需要复现早期布局时打开 [V1.2 离线网页](releases/v1.2/culvert-camera-lab-offline.html)。两个单页均内置 Three.js、OrbitControls、应用程序和样式。各版本的 `default-layout.json` 可通过页面顶部“导入方案”载入。两份 JSON 来自本次干净浏览器的原生导出，移除了导出时间，逐字段核对过相应内嵌默认值。2026-10-23 上传的原始 JSON 仅在历史交接中有引用。

## 调整视图与保存

选择主云台、上后摄或下后摄，调整光心和姿态。主视图选择“三维透视”，拖动旋转后点击“导出高清图”。默认导出长边 3840 像素的 PNG，短边随视口尺寸变化。页面还可选择 1920 或 5760 像素、背景色与相机名称。用“导出参数”保存三机、涵洞、车体及显示参数。需要保留观察者的当前构图时，同时保存 PNG。V1.3 导入旧方案时会将两台后摄镜头统一为 4 mm 档。

## 两版默认布局

以车中心的地面投影为原点，x 朝车头、y 朝车左、z 向上。偏航正值朝左，俯仰正值抬高。三机均启用、滚转 0°、量程 4 m、3840 × 2160、快门 1/500 s。涵洞净宽与总高各 2 m，直墙高 1 m，模拟段长 10 m。底盘长宽高为 0.80、0.61、0.67 m，位于中心，默认车速均为 0.20 m/s。

| 相机 | 光心 x / y / z（m） | 偏航 / 俯仰 | V1.2 水平 / 垂直视场、帧率 | V1.3 水平 / 垂直视场、帧率 |
| --- | --- | --- | --- | --- |
| 主云台 | 0.16 / 0 / 0.87 | 35° / 20° | 68.38° / 41.83°，25 fps | 68.38° / 41.83°，25 fps |
| 上后摄 | −0.40 / 0 / 0.97 | 91.3° / −21.4° | 58.30° / 34.84°，25 fps | 79° / 43.3°，20 fps |
| 下后摄 | −0.40 / 0 / 0.75 | 120° / −50° | 58.30° / 34.84°，25 fps | 79° / 43.3°，20 fps |

V1.2 后摄是候选广角镜头，垂直角按 16∶9 联动。V1.3 采用海康威视 DS-2CD3T86FWDV3-LS 的 4 mm 标称水平、垂直视场，关闭联动。`version: 1` 是两份 JSON 共用的方案格式版本。所有安装位置与姿态均属布局输入，真实外参、录像帧率与缺陷辨识需要现场测量。

## 查看几何与源码

在 [geometry.js](source/v1.2/dist/geometry.js) 中，`cameraPose`、`cameraRay` 和 `traceRay` 构造针孔视场并求相机射线到洞壁、拱、地面或车体的首次交点。`perimeterPoints` 按弧长采样，`coverageGrid` 用 64 个周界区间和 112 个轴向位置做可见性判定，同一周界区间只要至少一列可见即计入。`cameraMetrics` 在中心交点切平面上估算最不利方向的投影密度，按曝光期间车辆位移估算像面拖影。周界统计包括拱和两侧直墙，地面不参与分母。

两版在各自默认参数下单程覆盖 34/64 个区间。将居中的车体偏航设为 180° 再算一遍，去返重叠 4/64，周界区间并集 64/64。这项离散几何结果不能直接推算整段全部壁面累计成像、真实录像质量、2 mm 缺陷检出率或车辆通过能力。计算文档另取 0.80 m/s，对应 25 fps 主云台每帧前进 32 mm、20 fps 后摄每帧前进 40 mm。[录像覆盖计算原文](docs/录像覆盖计算-原文转录.md)

V1.2 的 `source/v1.2/dist` 是从公开站点逐文件取回的模块版。可在本目录运行下列命令，再在浏览器打开 `http://127.0.0.1:8000/`。JS 与 CSS 保留取回的字节；入口采用同站返回的干净应用 HTML，与站点根响应去掉托管平台注入的挑战脚本后逐字节相同。

```sh
python -m http.server 8000 --bind 127.0.0.1 --directory source/v1.2/dist
```

V1.3 的可读源码随原发行单页保留；两个版本的 `embedded-source-map.json` 均列出样式、几何、场景、软件渲染、交互和第三方依赖的起止字节、起始行及 SHA-256。字节范围使用左闭右开约定。修改模块版不会自动生成离线包。
